## 1. Executive Summary

This Requirements Traceability Matrix (RTM) establishes bidirectional traceability between the research objectives defined in the AquaSense-IoT project specification and the implementation across the Next.js frontend, FastAPI backend, PostgreSQL database models, machine learning inference pipeline, and FAO-56 irrigation decision engine.

Every requirement has been audited directly against the actual codebase, running database records, and active services.

## 3. Discrepancy Root-Cause Analysis (REQ-06 & REQ-08)

### Observed Inconsistency
During preliminary testing, four different moisture figures appeared across the dashboard:
- **Overview Card:** `0.225 m³/m³`
- **Soil Moisture Page:** `0.220 m³/m³`
- **Prediction History:** `0.225 m³/m³`
- **Irrigation Advisory:** `0.009 m³/m³` with reported depletion $D_r = 180.6\text{ mm}$ (exceeding TAW of 102 mm by 78 mm)

### Root Cause Traced
1. **Unvalidated Manual Override:** The recommendation trigger modal in the frontend allowed an arbitrary string/number in `soil_moisture_m3m3`. A value of `0.009` was submitted directly to `POST /api/v1/irrigation/fields/{id}/recommend`.
2. **Missing Hydraulic Lower Bound Validation:** In `backend/app/services/decision_engine.py`, `calculate_depletion` computed $1000 \times (0.31 - 0.009) \times 0.6 = 180.6\text{ mm}$ without verifying whether $\theta_{current} \ge \theta_{WP}$ ($0.14\text{ m}^3/\text{m}^3$). A value of $0.009\text{ m}^3/\text{m}^3$ is desiccated, physically impossible for agricultural topsoil under field conditions, and should have triggered an immediate validation failure or critical data-quality warning.
3. **Field ID Mismatch:** The in-situ telemetry observation (`0.220 m³/m³`) was recorded for Field 2 ("Cotton"). When viewing Field 1 ("Kurnool Precision Groundnut Plot 1"), which had no telemetry, the Overview and Prediction endpoints fell back to the unweighted midpoint $(0.31 + 0.14) / 2 = 0.225\text{ m}^3/\text{m}^3$ without an explicit `PROVISIONAL_FALLBACK` warning badge.
4. **Decoupled Calculation and Explanation:** The explanation string reported the raw manual override `0.009`, while the field overview displayed the fallback `0.225`.

### Resolution Applied
- Implemented `CanonicalDecisionInput` enforcing physical and agronomic boundary checks:
  $$\theta_{WP} \le \theta_{current} \le 0.60$$
- If an input $\theta < \theta_{WP}$ is encountered, the engine generates an explicit **Investigation Warning** and flags the recommendation as provisional or indeterminate.
- Synchronized all pages so that the active field ID strictly dictates telemetry retrieval, with fallback states clearly marked with the `PROVISIONAL` provenance badge.
